# Handoff: Migração para cookie-auth + acomodação de spec drift (priority, CANCELLED)

**Data:** 2026-05-10
**Status:** aguardando validação visual (typecheck/lint passam; dev server ainda não foi iniciado nesta sessão)

## 1. Objetivo

- Substituir o `openapi/worklog.json` por nova versão do backend que (a) preenche gaps e (b) trocou autenticação por **cookies HttpOnly** (`worklog_access` + `worklog_refresh`), no lugar de Bearer tokens em localStorage.
- Refazer o frontend para não persistir tokens, remover o header `Authorization: Bearer`, e enviar cookies automaticamente via `withCredentials: true`.
- Como efeito colateral do regen, o spec passou a exigir `TicketRequest.priority` (obrigatório) e expôs `TicketResponseStatus.CANCELLED`; o usuário aprovou os ajustes mínimos para acomodar.

## 2. Contexto essencial

- **Stack**: Next.js 16 + React 19, TanStack Query v5, axios 1.15, zustand 5, orval 8.8 (geração tipada do client + Zod), zod v3 (resolvers), react-hook-form 7.73, Tailwind v4, shadcn.
- **Package manager**: `pnpm` (não `npm`/`yarn`).
- **Auth — decisões trancadas nesta sessão**:
  - Cookies HttpOnly carregam o JWT. JS **não consegue** ler o cookie → "logado" deixou de ser "existe token em localStorage" e passou a ser "`GET /users/me` retorna 200".
  - `useAuthStore` agora só guarda `user` (preenchido pelo layout via `useGetMe`).
  - Refresh: interceptor de resposta 401 chama `POST /auth/refresh` **sem body** (o cookie `worklog_refresh` carrega tudo). Single-flight lock mantido.
  - `withCredentials: true` no axios `create` — sem isso o browser não envia cookies cross-origin (dev: `http://localhost:3000` → `http://localhost:8080`).
- **`ChangePasswordRequest.refreshToken`** segue no spec como **opcional** (não `required`). Pulamos no payload — backend deve aceitar ausência, pois cookie já autentica.
- **Spec drift acomodado** (escolhas do usuário):

  - `TicketResponseStatus.CANCELLED` agora existe no backend → mapping aceita, mas UI ainda **não escreve** CANCELLED (sem ação "Cancelar ticket"); só renderiza read-only.
- **Hooks** do projeto (`.agent-md/`) bloqueiam Stop com:

  - `visual-evidence` — exige markdown em `.agent/visual/` referenciando uma imagem **fresca** quando UI files mudam.

## 6. Perguntas em aberto

- **CSRF**: cookies HttpOnly + `withCredentials: true` reabrem superfície de CSRF. Backend tem CSRF token? `SameSite=Strict` (mencionado no `summary` do `POST /auth/login`) ajuda, mas vale confirmar com o autor do backend.
- **CORS dev**: para o browser enviar cookies cross-origin, o backend precisa responder `Access-Control-Allow-Credentials: true` e `Access-Control-Allow-Origin` específico (não `*`). Vale checar antes de bater no fluxo real.
- **Quando "Cancelar ticket" vira ação na UI?** Hoje CANCELLED é só leitura. Se o produto quiser expor, mover `'CANCELLED'` para fora do `Exclude` em `UiWritableStatus` e adicionar entrada em `UI_TO_API` + `UI_STATUS_WRITABLE`.
- **Mantém `data` no `useGetMe` infinito?** O layout depende de `useGetMe()` sem `staleTime`/`gcTime` explícitos. Se quiser revalidar agressivamente (ex.: foco), considerar opções no `query`.
- **`backend-gaps.md`** — atualizar removendo gaps que o novo spec fechou; conferir se há gaps novos.

### Snippet — núcleo do `src/lib/api.ts` (refresh por cookie)

```ts
export const api = axios.create({
  baseURL,
  withCredentials: true,
  headers: { 'Content-Type': 'application/json' },
  paramsSerializer: { serialize: (p) => serializeParams(p as Record<string, unknown>) },
})

let refreshPromise: Promise<void> | null = null

api.interceptors.response.use(
  (response) => response,
  async (error: AxiosError) => {
    if (typeof window === 'undefined') throw error
    if (error.response?.status !== 401) throw error

    const originalRequest = error.config as
      | (AxiosRequestConfig & { __retried?: boolean })
      | undefined
    if (!originalRequest || originalRequest.__retried) {
      forceLogout()
      throw error
    }

    const url = originalRequest.url ?? ''
    if (url.includes('/auth/refresh') || url.includes('/auth/login')) {
      forceLogout()
      throw error
    }

    refreshPromise ??= refreshSession().finally(() => {
      refreshPromise = null
    })

    try {
      await refreshPromise
      originalRequest.__retried = true
      return api(originalRequest)
    } catch (refreshErr) {
      forceLogout()
      throw refreshErr
    }
  },
)

async function refreshSession(): Promise<void> {
  await axios.post(`${baseURL}/worklog/auth/refresh`, undefined, {
    withCredentials: true,
  })
}
```

### Snippet — gate via `useGetMe` em `src/app/(app)/layout.tsx`

```tsx
const { data, isLoading, isError, error } = useGetMe({
  query: { retry: false },
})

useEffect(() => { if (data) setUser(data) }, [data, setUser])

useEffect(() => {
  if (!isError) return
  const status = (error as { response?: { status?: number } } | null)?.response?.status
  if (status === 401) router.replace('/login')
}, [isError, error, router])

if (isLoading || isError || !data) return null
return <AppShell>{children}</AppShell>
```
