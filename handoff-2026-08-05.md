### Paginação (contrato novo de 2026-08-04)

- `GET /clients` aceita `page`, `size`, `sort`. **É opt-in e troca o tipo da resposta:**
  sem `page`/`size` volta `ClientResponse[]`; com qualquer um dos dois volta
  `Page<ClientResponse>`.
- `sort` **sozinho é ignorado** — só vale acompanhado de `page`/`size`.
- O springdoc não expressa retorno duplo, então o Orval tipa **sempre** array: o cast
  fica na fronteira.
- `pageable` aparece como **obrigatório** no gerado. **Não é objeto que vá para o
  servidor:** o `paramsSerializer` de `src/lib/api.ts` achata objetos aninhados, então
  `pageable: { page, size, sort: ['name,asc'] }` sai como
  `?page=0&size=11&sort=name,asc`. Verificado na rede: nenhuma chave `pageable` chega.
- Telas que **não** paginam passam `pageable: {}` e seguem recebendo o array cru.

### CNPJ válido gerado em tempo de execução

`documento` é único **globalmente**: repetir volta 409. Cada rodada precisa de um novo.

```js
function cnpjValido(seed) {
  const base = String(Date.now() + seed).slice(-8).padStart(8, '0') + '0001'
  const v = base.split('').map((c) => c.charCodeAt(0) - 48)
  const dv = (w) => {
    let s = 0
    for (let i = 0; i < w.length; i++) s += v[i] * w[i]
    const rest = s % 11
    return rest < 2 ? 0 : 11 - rest
  }
  const d1 = dv([5, 4, 3, 2, 9, 8, 7, 6, 5, 4, 3, 2])
  v.push(d1)
  return base + d1 + dv([6, 5, 4, 3, 2, 9, 8, 7, 6, 5, 4, 3, 2])
}
```

### Armadilhas já pagas (estão no `gotchas.md`)

- **Classes Tailwind concorrentes com a mesma especificidade**: `` `${inputCls} w-28` ``
  não reduz a largura, quem vence é a ordem do CSS gerado. Colapsou um campo para 26px
  e depois deixou um `<select>` transparente. Escrever por extenso.
- **`style` inline vence classe** — por isso a borda dos campos saiu do `style` para
  classe, senão o `focus:` nunca apareceria.
- **Clique em botão dentro de campo dispara o `blur` do campo** — a lupa consultava a
  Receita duas vezes. Dedupe por `useRef`.
- **`t.status as TicketStatus` é cast falso**: `STATUS_META` é indexado pelo vocabulário
  da UI, não pelo da API. Usar `apiToUiStatus`.
- **Mock de erro de API precisa ser `new AxiosError(...)`** de verdade: os acessores
  usam `instanceof` e ignoram objeto parecido em silêncio.
- **`contatos` no PATCH substitui a lista inteira** — daí `emOrdemCompacta` manter os
  extras no array.

- Não consultar a Receita de verdade em verificação — abortar a rota ou stubar.
- Não auto-avaliar UI. Screenshot + asserção de valor computado.
