## 2. Contexto essencial

- **Stack:** Next.js 16 + React 19, App Router, TanStack Query v5, react-hook-form, zod/v3 (não `zod` direto — resolvers v5 rejeita zod v4), Tailwind CSS v4
- **Variáveis CSS:** `--wl-surface`, `--wl-surface-2`, `--wl-border`, `--wl-text`, `--wl-text-muted`, `--primary`
- **API gerada:** `src/api/generated/` via Orval; **nunca editar manualmente**; regenerar com `pnpm orval`
- **Invalidação de cache:** centralizada em `src/api/invalidate.ts`
- **Dropdowns em modal:** `position: absolute` é clipado por `overflow-y-auto`. Solução definitiva: `createPortal` para `document.body` com `position: fixed` + flip detection via `getBoundingClientRect()`
- **Filtro de clientes:** `GET /clients?filtersParams.status=ATIVO` retorna 403 — filtrar client-side via `c.enabled !== false`

### Padrão portal (replicar para novos dropdowns)
```tsx
import { createPortal } from 'react-dom'

function openDrop() {
  if (!triggerRef.current) return
  const r = triggerRef.current.getBoundingClientRect()
  const spaceBelow = window.innerHeight - r.bottom
  if (spaceBelow < 200) {
    setPos({ bottom: window.innerHeight - r.top + 4, left: r.left, minWidth: r.width })
  } else {
    setPos({ top: r.bottom + 4, left: r.left, minWidth: r.width })
  }
  setOpen(true)
}

// No render:
{open && pos && createPortal(
  <div style={{ position: 'fixed', zIndex: 9999, ...pos,
    background: 'var(--wl-surface)', border: '1px solid var(--wl-border)' }}>
    {/* opções */}
  </div>,
  document.body
)}
```
