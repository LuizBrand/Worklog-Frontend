- IDs sempre `publicId` (UUID)
- `POST /clients/` **com barra final** — o mapeamento é literal

  não-ignorado trava o Stop hook para sempre. Corrigido, mas o padrão vale para hooks novos.
- **`.githooks/pre-commit` exige `memory/progress.md` staged junto da fonte.** Isso torna
  caro dividir trabalho contínuo em vários commits.
- **`pkill -f "spring-boot:run"` mata o processo do usuário também.** Usar `TaskStop` com o
  id da task de background.
- **Cast na fronteira do Orval precisa de `as unknown as`** quando o tipo estrito tem
  `campo: string | null` e o gerado tem `campo?: string` — os dois não são mutuamente
  assinaláveis, e o `as` simples é recusado pelo `tsc`.

### Gotchas ainda válidos das sessões anteriores

- **`PATCH /clients` ignora `branches`.** Toda manutenção de filial é pelo sub-recurso.
- **`contatos` no PATCH de filial SUBSTITUI a lista inteira** e recria os contatos (os
  `publicId` mudam). Mandar sempre a lista completa.
- **`isMatriz: true` no POST de filial volta 422.** Promover é operação do PATCH.
- **A matriz nunca pode ser inativada nem rebaixada.**
- **`documento` é único GLOBALMENTE**, inclusive de filial inativa.
- **Assimetria 400/422:** checksum inválido volta **400 com `fieldErrors`** no
  `POST /clients/` e **422 com mensagem solta** no `POST /branches`.
- **Mensagens de 404/409 são em inglês e contêm IDs** — não exibir cru. As de 422 são pt-BR.
- **Nunca adicionar header customizado** — o CORS bloqueia no preflight.
- **`var(--wl-surface-1)` não existe.** São `--wl-surface`, `--wl-surface-2`, `--wl-bg`.
- **Prefix-match de query key do React Query é por elemento do array.**
  `['/clients/abc']` não invalida `['/clients/abc/branches']`.
- **MCP do Playwright não funciona neste ambiente** — canal `chrome` ausente. Usar o
  `playwright` das devDependencies, rodando da raiz.
- **Hook de evidência visual exige os 5 campos com dois-pontos na mesma linha**
  (`**Changed files:** ...`).
